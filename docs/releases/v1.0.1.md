## DWS Assistant 1.0.1 / DWS助手

本次更新完善会话权限与原生审批，增加本机 CLI 工具管理，并修复交互卡片提交问题。

**2026-11-19 重新发布（构建号 3）**：补充表情与空内容消息处理修复。已下载此前 v1.0.1 安装包的用户，请重新下载安装；版本号仍为 1.0.1。

### 更新内容

- **表情与图片读取**：普通 emoji 按文本处理，空内容消息直接跳过，不再误触发图片详情读取。当前 DWS 渠道拒绝读取消息内容时，面板与卡片会提示改用文字描述，后续文字消息可继续处理。
- **Codex 原生审批**：提供「只读」「请求批准」「帮我批准」「完全访问权限」四种模式，创建和恢复会话时核验实际权限。在「请求批准」模式下，可通过钉钉卡片或助手面板处理同一个审批请求，决定返回原引擎进程，重复点击只生效一次；超时、停止服务或配置改变后失效。
- **更多引擎**：增加 QoderWork、OpenCode、WorkBuddy、CodeBuddy、Pi 和自定义 Agent 接入，各引擎展示其支持的权限选项。
- **CLI 工具管理**：在设置中查看已安装版本、检测安装、检查更新，并按需安装或更新工具；补充本地图标和来源许可。
- **交互卡片修复**：修复确认按钮持续灰显，以及提交后重开流式状态导致任务中断的问题，完善等待与执行超时提示。
- **身份与任务上下文**：向引擎传递宿主已核验的发送者身份、当前会话目标和适用规则，完善登录状态异常的说明。
- **数据兼容与资源整理**：统一 Assistant 模块命名，兼容迁移旧数据目录、会话绑定和卡片协议，清理废弃资源。

### 升级与安装

- 安装包：**DWS-Assistant-1.0.1-arm64.dmg**，适用于 **Apple Silicon（M 系列芯片）及 macOS 14 或更高版本**。
- 先退出旧版应用，再打开 DMG，将 **DWS Assistant.app** 拖入 **Applications** 替换旧版。DWS CLI 与所用 AI 引擎仍需安装并登录。
- 旧 `~/.dws-dashboard` 数据会迁移到 `~/.dws-assistant`，保留已有配置和会话绑定；新旧目录同时存在且内容独立时会停止迁移，避免覆盖。
- 旧「宽松执行」配置对应「帮我批准」。要使用卡片和面板的人工审批，请在目标会话的「AI 回复设置 → 执行权限」选择「请求批准」。
- 安装包采用 ad hoc 签名，尚未经过 Apple 公证。首次打开若被 macOS 拦截，可在「系统设置 → 隐私与安全性」中对本次下载选择「仍要打开」。

### 校验与验证

将 DMG 和 `.sha256` 文件下载到同一目录后执行：

```sh
shasum -a 256 -c DWS-Assistant-1.0.1-arm64.dmg.sha256
```

已通过 217 项 Swift 回归测试及 Go 桥接测试；审批链路与消息权限拒绝使用本地模拟引擎和卡片事件验证。安装包完成正式构建、签名验证与磁盘映像完整性检查。

## English

DWS Assistant 1.0.1 adds native Codex approvals through either DingTalk cards or the assistant panel, engine-specific permission modes, more AI channels, and local CLI installation/version management. It fixes disabled card submission buttons and interrupted card continuations, passes verified sender context to engines, and preserves existing settings and chat bindings during the Assistant data-directory migration.

**Republished on November 19, 2026 (build 3):** Ordinary emoji remain text, and empty messages are skipped without fetching image metadata. If the DWS channel denies access to message content, the panel and card ask for a text description; later text messages still work. Download the installer again if you already installed the earlier 1.0.1 package. The version remains 1.0.1.

**Download:** `DWS-Assistant-1.0.1-arm64.dmg` for **Apple Silicon and macOS 14 or later**. Quit the previous app, open the image, and replace **DWS Assistant.app** in **Applications**. DWS CLI and the selected AI engine require their own installation and sign-in.

Existing relaxed permissions retain auto-review. Select **Ask for approval** in the chat's execution permissions to use manual approval from either surface. The app is ad hoc signed and has not been notarized by Apple; if the first launch is blocked, use **System Settings → Privacy & Security → Open Anyway** for this download.

Download the accompanying `.sha256` file and verify it with the command above. Validation includes 217 Swift tests, Go bridge tests, a release build, signature verification, and DMG integrity checks. Approval flows and denied message reads are tested using local mock engines and card events.
